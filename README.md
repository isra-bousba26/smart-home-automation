# Smart Home Automation System

An IoT-based Smart Home Automation System developed using Arduino UNO, ESP8266, environmental sensors, and servo motors as a Bachelor's Capstone Project in Telecommunications and Wireless Networks. The project combines real-time environmental monitoring, wireless communication, manual device control through a mobile application, and automated responses to improve home safety, convenience, and energy efficiency.

---

## Project Overview

This project presents the design and implementation of an intelligent home automation system based on Internet of Things (IoT) technologies. The system continuously monitors environmental conditions using multiple sensors and allows users to remotely monitor and manually control selected home devices through a mobile application.

In addition to manual control, the system performs automatic actions based on sensor readings. A dedicated servo-driven retractable laundry drying rack automatically moves clothes indoors when rainfall is detected, protecting them from getting wet without requiring user intervention. The system also detects gas leaks, fire, motion, temperature, humidity, and ambient light conditions to enhance home safety and comfort.

## System Operation

The Arduino UNO continuously collects data from multiple environmental sensors and processes it according to predefined control logic.

Users can monitor system information and manually control supported devices through a mobile application connected via the ESP8266 Wi-Fi module.

The system also performs automatic actions without user intervention. For example:

- When rain is detected, the retractable laundry drying rack automatically moves indoors to protect clothes.
- When a gas leak or fire is detected, audible alarms are activated and the emergency water pump can be triggered.
- Indoor and outdoor lighting is automatically adjusted according to ambient light conditions.
- Temperature and humidity measurements are continuously displayed on the LCD screen and transmitted to the mobile application.
